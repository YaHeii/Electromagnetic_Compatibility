周报-实验汇总

1. 总述

本文将 experiment1.ipynb、experiment2.ipynb、experiment3.ipynb 的实验结果统一整理为一份报告，重点说明实验步骤、评价指标、结果及结论，并保留理解实验链路所必需的最小原理背景。

本组实验的验证链路可概括为：

Two-Ray -> FDTD -> PE-PLST -> 编队 EMC

  • Two-Ray：平坦海面条件下的解析基准，用于验证改进后的 PE 在理想双路径传播场景中不会引入额外数值误差，同时解释海面直射波与反射波叠加形成的双路径干涉现象。
  • FDTD：直接求解麦克斯韦方程组的全波参考解，用于在有限尺度场景下对 PE-PLST 的精度进行数值对标。
  • PE-PLST：本文的核心高效传播模型，其中 PE 负责远距离前向传播建模，PLST 负责处理粗糙海面或分段线性下边界带来的边界修正问题。
  • JONSWAP：用于生成不同风速下的海面粗糙度，是实验二和实验三中海况建模的基础。

三组实验共同构成了一条完整证据链：实验一验证退化场景与网格设置的正确性，实验二验证多海况下 PE-PLST 相对 FDTD 的精度与效率优势，实验三进一步将该传播模型应用于编队电磁兼容（EMC）分析。

2. 实验一：退化验证与网格收敛性分析

2.1 实验目的

实验一用于验证两件事情：

  1. 当海浪高度和风速退化为零时，改进后的 PE 模型能否正确还原平坦海面传播结果，并与双射线解析解保持一致。
  2. 当采用分段线性位移变换处理海面边界时，数值解是否随垂向步长 Δz 的减小而稳定收敛，从而为后续复杂海况计算选择合适网格。

2.2 基本原理

平坦海面条件下，传播场主要由直射波和海面反射波构成，因此双射线模型可作为解析基准。若改进 PE 在这一退化场景下仍能得到与双射线模型一致的传播趋势，就说明位移变换并未破坏基本物理机制。

另一方面，网格收敛性分析属于 PE 模型的内部自证：若同一场景下 Δz 越小，结果越趋于稳定，则说明算法具有良好的数值一致性。本文以最细网格 Δz = 0.05 m 的结果作为拟似真实解，并比较其他步长的 RMSE。

2.3 实验步骤

2.3.1 平坦海面退化验证

  1. 将风速、海浪高度等海况参数置零，构造平坦海面场景。
  2. 使用双射线解析模型计算二维场分布和一维距离切片。
  3. 使用退化后的 PE 模型计算相同场景下的传播结果。
  4. 对比二维场强分布图与一维切片曲线，并计算归一化 RMSE。

2.3.2 网格收敛性分析

  1. 选取固定粗糙海面场景，仅运行 PE 求解器。
  2. 设置垂向步长 Δz = [0.8, 0.4, 0.2, 0.1, 0.05] m。
  3. 以 Δz = 0.05 m 的结果作为拟似真实解。
  4. 计算较粗网格相对于拟似真实解的一维 RMSE。
  5. 根据误差与效率的平衡，确定后续复杂场景采用的推荐网格。

2.4 评价指标

实验一的核心评价指标为均方根误差（RMSE）：

RMSE=1N∑i=1N(L1(i)−L2(i))2RMSE = \sqrt{\frac{1}{N}\sum_{i=1}^{N}\left(L_1(i)-L_2(i)\right)^2}RMSE=N1​i=1∑N​(L1​(i)−L2​(i))2​

其中，L1 与 L2 分别表示待比较的两组场强结果。根据 notebook 中采用的判据：

  • RMSE < 1 dB：极好，说明两者高度一致。
  • 1 dB <= RMSE < 3 dB：良好，说明误差可接受。

2.5 实验结果

2.5.1 平坦海面退化验证结果

  • 平坦海面一维切片归一化误差：RMSE = 0.5611 dB
  • 结果评价：极好

该结果说明退化后的 PE 模型在平坦海面条件下能够很好复现双射线模型的传播趋势。二维热图中，近场及高仰角区域仍可见一定视觉差异，但一维远场主传播区间的吻合度很高，说明方法在核心传播区域内是可靠的。

2.6 小结

实验一表明：一方面，改进后的 PE 模型在退化为平坦海面时能够正确回归到双路径传播结果；另一方面，Δz = 0.1 m 已能在精度和效率之间取得较好平衡，因此可作为后续实验的统一网格设置。

3. 实验二：多风速海况下的 PE-PLST 与 FDTD 综合对比

3.1 实验目的

实验二在相同场景和参数条件下，对比 PE-PLST 与 FDTD 在九组风速海况中的传播结果，用以验证：

  1. PE-PLST 在粗糙海面下对全波解的拟合精度；
  2. 不同风速条件下算法误差是否保持稳定；
  3. PE-PLST 相比 FDTD 是否具备数量级上的效率优势。

3.2 基本原理

FDTD 可以视为小尺度海上传播场景的高精度全波参考解，但计算成本较高；PE-PLST 则利用抛物方程的单向传播优势，在保留主要传播效应的同时显著降低计算量。若两者在多个风速海况下的传播趋势和 RMSE 保持良好一致，就说明该方法可用于复杂海况传播建模。

3.3 实验步骤

  1. 设定九组海况风速：U10 = [1.0, 1.5, 2.0, 2.5, 3.0, 3.5, 4.0, 4.5, 5.0] m/s。
  2. 基于 JONSWAP 谱为每组风速生成对应粗糙海面。
  3. 在同一 x-z 平面中分别运行 FDTD 与 PE-PLST。
  4. 将结果转换到统一参考下进行对比，并统计 50 m 之后传播区间的 RMSE。
  5. 汇总九组实验结果，分析误差稳定性和计算开销。

3.4 评价指标

实验二以 RMSE 作为主指标，以计算时间和峰值内存作为效率指标：

RMSE=1N∑i=1N(LPE(i)−LFDTD(i))2RMSE = \sqrt{\frac{1}{N}\sum_{i=1}^{N}\left(L_{PE}(i)-L_{FDTD}(i)\right)^2}RMSE=N1​i=1∑N​(LPE​(i)−LFDTD​(i))2​

此外，还关注：

  • 单组实验耗时（seconds）
  • 峰值内存（MB）

3.6 小结

实验二表明：PE-PLST 在九组不同海况下均能以约 1 dB 左右的 RMSE 逼近 FDTD 全波结果，同时计算速度提升达到数量级优势，因此具备在更大尺度、更复杂海况中的应用潜力。

4. 实验三：编队场景下的 EMC 指标分析

4.1 实验目的

在实验一和实验二完成方法正确性验证后，实验三进一步将 PE-PLST 应用于无人艇编队的电磁兼容分析，目标是构建并验证一套适用于编队场景的指标体系，用于评估系统级干扰强度、海况敏感性、背景噪声抬升及接收机灵敏度恶化程度。

4.2 场景说明

实验三采用 A/B 两组对照场景，场景设计口径遵循 DESIGN.md：

  • Case A：违规高危态

    • 编队保持紧凑 V 型构型，舰间距较小。
    • 发射机采用高功率同频工作方式。
    • 波束指向对友邻节点不友好，更容易在编队内部形成强干扰。
    • 用于模拟忽视 EMC 管控时的高风险状态。

  • Case B：合规安全态

    • 编队进行空域展开，增大舰间距。
    • 发射功率降低，并采用频域/滤波隔离策略。
    • 波束尽量背向编队中心，减小内部耦合。
    • 用于模拟实施 EMC 管控后的优化状态。

4.3 基本原理与评价指标

实验三使用四项指标来量化编队 EMC 状态。

4.3.1 系统级电磁耦合度 SCF

SCF 用于衡量编队内部非目标链路的平均干扰强度。其值越低，说明编队频谱规划和空间部署越合理。

4.4 实验步骤

  1. 分别加载 Case A 和 Case B 的编队配置。
  2. 基于 PE-PLST 计算编队内各节点之间的传播与干扰强度。
  3. 构建系统耦合矩阵并计算 SCF。
  4. 在平静海况与粗糙海况之间对比链路传播曲线，计算 S3I。
  5. 在编队活动海域上计算总干扰功率，生成 T_elev 热图。
  6. 以受害接收机为对象，生成 D_desense 分布图，并统计恶化强度。

4.7 小结

实验三说明，经过前两组实验验证后的 PE-PLST 模型不仅能用于单链路传播分析，还可以支撑编队级电磁兼容评估。A/B 对照结果显示，编队空域展开、功率控制和频域隔离能够显著降低系统级耦合和灵敏度恶化风险，因此该方法具备明显的工程指导价值。

5. 总结

三组实验从不同层次验证了本文方法的有效性：

  1. 实验一 通过双射线退化验证和网格收敛分析，证明了改进 PE 模型在理想场景下的正确性，并确定了后续统一采用的网格步长 Δz = 0.2 m。
  2. 实验二 通过九组风速海况下与 FDTD 的全波对标，证明 PE-PLST 在保持约 1 dB 量级误差的同时，具备数量级上的效率优势。
  3. 实验三 进一步将传播模型推广到编队 EMC 场景，建立了 SCF、S3I、T_elev、D_desense 四项指标组成的分析框架，并通过 A/B 对照展示了优化策略的效果。

综上，本文所采用的 PE-PLST 方法不仅在退化验证和全波对标中表现可靠，而且能够进一步服务于复杂海况下的编队电磁兼容分析，为后续工程设计与方案优化提供可量化、可解释的技术支撑。
